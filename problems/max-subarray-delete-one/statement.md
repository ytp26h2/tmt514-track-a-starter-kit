# 刪一個也可以：最大子陣列和

給定長度為 $n$ 的整數陣列 $a_1, a_2, \dots, a_n$。

請選一段**非空**的連續子陣列 $a_l, \dots, a_r$，你**可以選擇**從中刪除至多一個元素（也可以不刪），
但刪除之後子陣列仍必須**非空**。請輸出剩下元素總和的最大可能值。

## 輸入格式
第一行一個整數 $n$（$1 \le n \le 2 \times 10^5$）。
第二行 $n$ 個整數 $a_i$（$|a_i| \le 10^9$）。

## 輸出格式
輸出一個整數，代表最大總和。

## 範例
輸入
```
3
5 -100 5
```
輸出
```
10
```
