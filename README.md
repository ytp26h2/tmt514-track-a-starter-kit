## 這個 Repo 是什麼
- 本競賽**所有評審依據皆以此 Repo 為準**：沒有推送上來的，等同沒有交付。
- Repo 由主辦統一配發，隊員為 Write 權限；無法刪除、無法改可見性、無法移除隊員。

## E1 課後作業（9/26 五 截止）
1. 每位隊員各自在此 Repo 完成至少一次 commit（證明帳號、收信、推送權限都正常）。
2. 填妥 `TEAM.md`（隊員名單，是名單凍結與現場驗身的比對依據）。
3. 完成一次完整 PR 循環：開分支 → 發 Pull Request → 隊友 review → 合併。

## 約定
- `main` 是交付分支，請以 PR 合併，不要直接 force push。
- 大型檔案（模型權重、影片、資料集 >50 MB）請勿放進 Repo，改用連結。
- GitHub Actions 為全 org 共用額度，除非必要請勿在每次 push 觸發 CI。
