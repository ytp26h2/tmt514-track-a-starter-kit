# Web 應用程式骨架

純 HTML＋JavaScript，不需要 build。後端同時提供這個頁面和 API。

```bash
python server/app.py      # 在 starter kit 根目錄
# 開啟 http://127.0.0.1:8787
```

## 畫面上有什麼

- **左邊**：資料包題目列表，可以用題號、題名、標籤搜尋，也能篩難度；「隨機抽一題」模擬評審抽測。
- **中間**：題敘、提交紀錄（WA／AC 程式碼）、用範例測資跑你的程式。
- **右邊**：AI 提示，示範規範三的完整流程——即時呼叫 → 固定 JSON → 程式檢查（不可以有程式碼、不可以太長）→ 不合格就重試。下拉選單可以模擬「格式壞掉」和「逾時」，練習出錯處理。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 版面 |
| `style.css` | 樣式 |
| `app.js` | 呼叫後端 API、畫面邏輯；`api()` 是唯一和後端溝通的地方 |

## 想改用框架

用 Vite、React、Vue 都可以：把 `app.js` 的 `api()` 搬過去，並在 starter kit 根目錄的 `.env` 加上
`ALLOWED_ORIGINS=http://localhost:5173`（換成你的開發伺服器網址）。題敘裡的數學式目前是原樣顯示 `$…$`，可以自己接 KaTeX。
